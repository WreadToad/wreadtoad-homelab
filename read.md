# WreadToad Home Lab

This repository documents hands-on cybersecurity practice in a
VMware-based home lab, using Kali Linux and Metasploit for offensive
activity, and Splunk Enterprise as the SIEM for log ingestion and
investigation.

## Structure
- `/homelab` — full documentation of the virtual environment
- `/notes` — quick-reference commands and filters
- `/investigation-template` — templates for SOC-style investigations
- `/Connection` — connection setup, configs, and environment linking

## Environment
- **Virtualization:** VMware
- **Offensive tools:** Kali Linux, Metasploit
- **SIEM:** Splunk Enterprise
- **Traffic analysis:** Wireshark
